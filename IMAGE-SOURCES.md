# Image sources & licences — Kitchen Gadgets (Bright Picks)

**Purpose:** a compliance/audit record of every image used on the site — where it
came from, its licence, and why. Keep this current whenever an image is added,
swapped or removed.

---

## Policy in force

1. **No Amazon product images** until Product Advertising API (PA-API) access is granted.
2. **No manufacturer / press images** unless a licence clearly permits affiliate/review reuse.
3. If real photos are used, prefer **openly-licensed** repositories (Unsplash / Pexels)
   that permit commercial use, label them on-page as a *representative image*, and credit
   the photographer.
4. Self-authored vector art (our own SVGs) may be used freely — we own it.

---

## Currently used

| Asset | Type | Used on | Licence |

original vector icons, so there is currently **no image-licensing exposure.**
